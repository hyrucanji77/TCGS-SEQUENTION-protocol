# Dimensional Accessibility and Gravitational Localization

Computational supplement to **Spectral Response, Boundary Stability, and Constitutive Constraints in TCGS–SEQUENTION**, Henry Arellano-Peña (29 October 2026).

## Scope

The programs evaluate a conditional static scalar half-line response. They do not fit observations, establish Counterspace empirically, or supply a relativistic tensor completion. The existing repository's biological analyses are independent of this supplement.

## Execution from the repository root

Python 3.10 or newer is required. The tested dependency versions are pinned in the adjacent requirements file.

```sh
python -m pip install -r docs/dimensional_accessibility/requirements.txt
python code/reproduce.py --output results/dimensional_accessibility
python code/verify_extensions.py --output results/dimensional_accessibility
python -m unittest discover -s tests -p test_dimensional_accessibility.py -v
```

The article package instead uses `--output results`, retaining its original filenames. A command without `--output` also writes to `results` relative to the script's repository/project root. No network or external dataset is required after dependencies have been installed.

## Outputs and actual checks

`reproduce.py` is the unchanged baseline implementation: **186 checks** and **12 table rows**. It writes `response_table.csv`, `response_rows.tex`, and `verification.json`. Checks include normalization, factorization, Bessel recurrence, spectral-resolvent equality, force differentiation and monotonicity, negative detuning, and arbitrary-precision controls.

`verify_extensions.py` writes `extension_verification.json`: **225 additional checks**. They cover the warped-action reduction, the three-in-four candidate, positive-measure finite differences, the Laplace/resolvent integrability distinction, detuned resonance poles, threshold ratios, and the AQUAL flux Jacobian. The lower incomplete gamma function is used to evaluate the near-zero Tonelli kernel without cancellation.

Three additional unittest smoke tests cover the exact kernel, an AQUAL eigenvalue example, and invalid arguments. They are not counted among the 411 numerical comparisons above.

The tracked `results/dimensional_accessibility/summary.json` records the executed environment and script SHA-256 hashes. The complete per-check reports, including actual tolerances, are generated by the commands above and accompany the article package. Floating-point values need to agree within those tolerances, not bit-for-bit across platforms. Finite numerical checks are not substitutes for the analytical proofs or certificates of an infinite inequality hierarchy.
