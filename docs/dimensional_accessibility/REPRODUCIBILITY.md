# Dimensional Accessibility and Gravitational Localization

Computational supplement to **Spectral Response, Boundary Stability, and Constitutive Constraints in TCGS–SEQUENTION**, Henry Arellano-Peña (29 October 2026).

## Scope

The programs evaluate a conditional static scalar half-line response. They do not fit observations, establish Counterspace empirically, or supply a relativistic tensor completion. The repository's biological analyses are independent of this supplement.

## Execution from the repository root

Python 3.10 or newer is required. The tested dependency versions are pinned in the adjacent requirements file. Check out the immutable commit cited in the manuscript before running these commands; `git rev-parse HEAD` identifies that revision.

```sh
python -m pip install -r docs/dimensional_accessibility/requirements.txt
python code/reproduce.py --output results/dimensional_accessibility
python code/verify_extensions.py --output results/dimensional_accessibility
python code/verify_geometry_constraints.py --output results/dimensional_accessibility
python -m unittest discover -s tests -p 'test_dimensional_accessibility.py' -v
python -m unittest discover -s tests -p 'test_geometry_constraints.py' -v
```

The article package instead uses `--output results`, retaining its original filenames. With no `--output`, the scripts also write to `results` relative to the project root. No network or external dataset is required after dependencies have been installed. The published coefficients are declared, documented numerical inputs; the programs do not download or infer experimental likelihoods.

## Outputs and checks

`reproduce.py` is the unchanged baseline implementation: **186 checks** and **12 table rows**. It writes `response_table.csv`, `response_rows.tex`, and `verification.json`. Checks include normalization, factorization, Bessel recurrence, spectral-resolvent equality, force differentiation and monotonicity, negative detuning, and arbitrary-precision controls.

`verify_extensions.py` is also unchanged: **225 checks**, written to `extension_verification.json`. They cover the warped-action reduction, the three-in-four candidate, positive-measure finite differences, the Laplace/resolvent integrability distinction, detuned resonance poles, threshold ratios, and the AQUAL flux Jacobian.

`verify_geometry_constraints.py` executes **118 checks**, written to `geometry_constraint_verification.json`, and generates `published_powerlaw_limits.json` and `cross_sector_hierarchy.json`. These outputs document the hyperbolic/flat distinction, localization threshold, force/potential conversion, historical coefficient provenance, and conditional comparison of the laboratory radius with an illustrative AQUAL scale.

There are **529 numerical comparisons** and **nine separate unittest tests**. The latter comprise the three original response tests and six geometry/provenance/hierarchy tests. Unit tests are not counted in the 529. All passed in the supplied run. Finite numerical checks do not certify analytical proofs, an infinite hierarchy of inequalities, or empirical interpretations.

The tracked `results/dimensional_accessibility/summary.json` records the executed environment and script hashes. Full per-check reports, including tolerances, are regenerated by the commands and included in the article package. Floating-point values should agree within those tolerances, not necessarily bit-for-bit across platforms.

## Source provenance

`published_powerlaw_limits.json` distinguishes the original experimental attribution from the table actually used for a coefficient and confidence convention. Hoskins et al.'s earlier k=2 limit is taken from Adelberger et al. Table I and corroborated by Hoyle et al. Table XIV. Hoyle's own weaker k=2 result is retained separately. The adopted 2007 value retains the table's **68% confidence convention**. No 95% claim or strongest-current-bound claim is made.

The illustrative acceleration in `cross_sector_hierarchy.json` is the central 2016 radial-acceleration calibration, not a newly fitted AQUAL scale. Its uncertainty is not combined with the laboratory constraint. The hierarchy is conditional on identifying the same curvature with the scale-setting functional.
