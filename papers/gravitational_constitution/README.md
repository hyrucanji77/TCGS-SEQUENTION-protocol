This self-contained directory provides the four verification programs for *Gravitational Constitution and Gauge Representation in TCGS–SEQUENTION: Constitutive Response, Geometric Completion, and Quantum Counterterms*. It is separate from the repository's other computational projects.

### Reproduction

From this directory, in a Python environment with the pinned dependencies:

```sh
python -m pip install -r code/requirements.txt
python code/verify_results.py
python code/verify_extensions.py
python code/verify_nonlinear_slab.py
python code/verify_model_discrimination.py
```

Default JSON outputs are written beside the programs. Each accepts `--output PATH`. A failed required check produces a nonzero exit. The programs require no network access after dependency installation.

### Scientific scope

The calculations cover reflecting and Dirichlet slab responses, the compactification identity, the 290/10 constitutive quotient, nonlinear thin-slab reduction, an exact constant-background tangent kernel, and a specified matched-gradient discriminator. The nonlinear reduction assumes a smooth uniformly elliptic branch; it does not cover the degenerate zero-gradient limit or arbitrary singular sources.

The real-space statistic is `R_WB = (|g_r(parallel)| / |g_r(transverse)|)^2`, comparing the internal radial force at equal separation and mass after removing the uniform background. For spherically matched interpolation functions and paired collinear constant backgrounds, `T_A = 0` and `T_Q = -(2-eta_M) ell^2/(2+ell)^2`. Newton belongs to the null class. Purely axial Fourier responses agree between AQUAL and QUMOND and are not this real-space statistic. The equipotential intercept ratio is not an observed binary-orbit axis ratio.

The sensitivity evaluation at `g/a_* = 1.8` is an illustrative model calculation, not a Galactic measurement or a forecast of catalogue precision. Modified-inertia theories require separate model-specific predictions. The Lee comparison is a historical one-Yukawa benchmark, not an apparatus-level fit of the complete tower.
