## Computational supplement — release 4

This self-contained directory provides all five verification programs for *Gravitational Constitution and Gauge Representation in TCGS–SEQUENTION: Constitutive Response, Geometric Completion, and Quantum Counterterms*. It is separate from the repository's other computational projects. Computational release 4 accompanies manuscript version 5; the manuscript and software version numbers are distinct.

### Reproduction

From this directory, in a Python environment with the pinned dependencies:

```sh
python -m pip install -r code/requirements.txt
python code/verify_results.py
python code/verify_extensions.py
python code/verify_nonlinear_slab.py
python code/verify_model_discrimination.py
python code/verify_empirical_reach.py
```

Default JSON outputs are written beside the programs. Each accepts `--output PATH`. A failed required check produces a nonzero exit. The programs require no network access after dependency installation.

These are finite algebraic and numerical consistency checks, not observations, empirical confirmation of an ontology, a proof of all analytic hypotheses, or an independent quantum-loop calculation. Numerical minimization uses two resolutions and checks stationarity and convergence; floating-point results can vary within the recorded tolerances.

The first four program files are unchanged from release 3. The fifth retains the 80 checks supplied with manuscript version 4 and adds 20 tests of tolerance-opening thresholds and the two sides of each boundary. `verification_summary.json` records the verified environment, all five Git blob identifiers, and SHA-256 checksums. Check the local program bytes with `cd code && sha256sum -c SHA256SUMS.txt`.

### Scientific scope

The calculations cover reflecting and Dirichlet slab responses, the compactification identity, the 290/10 constitutive quotient, nonlinear thin-slab reduction, an exact constant-background tangent kernel, and a specified matched-gradient discriminator. The nonlinear reduction assumes a smooth uniformly elliptic branch; it does not cover the degenerate zero-gradient limit or arbitrary singular sources.

The real-space statistic is `R_WB = (|g_r(parallel)| / |g_r(transverse)|)^2`, comparing the internal radial force at equal separation and mass after removing the uniform background. For spherically matched interpolation functions and paired collinear constant backgrounds, `T_A = 0` and `T_Q = -(2-eta_M) ell^2/(2+ell)^2`. Newton belongs to the null class. Purely axial Fourier responses agree between AQUAL and QUMOND and are not this real-space statistic. The equipotential intercept ratio is not an observed binary-orbit axis ratio.

The sensitivity evaluation at `g/a_* = 1.8` is an illustrative model calculation, not a Galactic measurement or a forecast of catalogue precision. Modified-inertia theories require separate model-specific predictions. The Lee comparison is a historical one-Yukawa benchmark, not an apparatus-level fit of the complete tower.

The fifth suite computes laboratory-to-astrophysical scale separation, conditional binary windows, local constitutive Taylor coefficients, and mass-profile uncertainty propagation. For the quadratic scenario with unit coefficient, increasing the tidal budget above 0.00205328414 at fixed nonlinear budget 0.001, or the nonlinear budget above 0.00260974898 at fixed tidal budget 0.001, opens the diagnostic interval. Equality gives only a touching separation. No nonlinear stellar two-body remainder, feasible observing window, or full residual-error budget is certified. See `EMPIRICAL_REACH.md` and `tolerance_thresholds.json`.
